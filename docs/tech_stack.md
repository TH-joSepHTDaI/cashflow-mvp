# Tech Stack

## Recommended Choices

To make OpenClaw execution easier, the first version recommends:

| Layer | Technology | Notes |
|-------|------------|-------|
| Frontend | Flutter | Cross-platform mobile app |
| Backend | FastAPI | Python async web framework |
| Database | SQLite | Lightweight local database |
| ORM | SQLModel / SQLAlchemy | Database model definition |
| Testing | pytest | Python testing framework |
| API Testing | httpx / FastAPI TestClient | API testing tools |

## Project Files

- `status.json` — Project status tracking
- `tasks.md` — Task board
- `decisions.md` — Decision log
