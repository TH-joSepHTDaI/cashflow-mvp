# 📋 产品需求文档 (PRD)

## Cashflow MVP - 个人记账应用

---

## 1. 产品概述

### 1.1 产品定位
一个极简的个人财务管理工具，帮助用户追踪日常收支、管理资产负债，并通过数据洞察改善财务健康。

### 1.2 目标用户
- 希望简单记账的个人用户
- 需要了解净资产状况的用户
- 想要分析月度现金流的用户

### 1.3 核心价值
- **简单** - 3秒完成一笔记录
- **清晰** - 一目了然看财务
- **智能** - 自动分类省时省力

---

## 2. 功能需求

### 2.1 交易记录 ⭐核心功能

**用户故事：**  
作为用户，我希望记录每一笔收入和支出，以便了解钱花在哪里。

**功能描述：**
- 记录交易金额、日期、分类、备注
- 支持收入、支出、投资、负债还款四种类型
- 根据关键词自动分类
- 按月查看交易列表

**验收标准：**
- [x] 可以创建、查看、修改、删除交易
- [x] 输入"工资"自动标记为收入
- [x] 输入"午餐"自动标记为支出
- [x] 可以按月筛选交易

---

### 2.2 资产管理

**用户故事：**  
作为用户，我希望追踪我的资产，以便了解我的财富积累。

**功能描述：**
- 记录各类资产：现金、银行存款、股票基金、房产
- 显示总资产价值

**验收标准：**
- [x] 可以添加、查看、删除资产
- [x] 实时计算总资产

---

### 2.3 负债管理

**用户故事：**  
作为用户，我希望记录我的负债，以便了解我的债务状况。

**功能描述：**
- 记录各类负债：信用卡、房贷、车贷、消费贷
- 显示总负债金额

**验收标准：**
- [x] 可以添加、查看、删除负债
- [x] 实时计算总负债

---

### 2.4 资产负债表

**用户故事：**  
作为用户，我希望看到我的净资产，以便了解我的真实财务状况。

**功能描述：**
- 计算净资产 = 总资产 - 总负债
- 显示资产和负债的分布

**验收标准：**
- [x] 实时显示净资产
- [x] 资产和负债分类展示

---

### 2.5 现金流分析

**用户故事：**  
作为用户，我希望按月查看收支情况，以便了解我的储蓄能力。

**功能描述：**
- 按月统计收入、支出、投资、负债还款
- 计算净现金流
- 按分类查看支出分布

**验收标准：**
- [x] 显示当月总收入和支出
- [x] 计算净现金流（收入 - 支出 - 投资 - 负债还款）
- [x] 支持查看历史月份

---

## 3. 非功能需求

### 3.1 性能要求
- API 响应时间 < 200ms
- 支持 1000+ 条交易记录流畅查询

### 3.2 可用性要求
- 移动端界面友好，支持 iOS 和 Android
- 离线数据缓存（未来版本）

### 3.3 安全要求
- 本地 SQLite 数据存储
- 未来版本支持用户认证

---

## 4. 技术架构

### 4.1 后端技术栈
- **框架**: FastAPI (Python)
- **数据库**: SQLite
- **ORM**: SQLModel
- **API 文档**: 自动生成 Swagger/OpenAPI

### 4.2 前端技术栈
- **框架**: Flutter
- **状态管理**: 简单 setState（MVP 版本）
- **HTTP 客户端**: http 包
