# Product Requirements

## Goal

Build a minimal personal cashflow tracking app.

## Features

- Record transactions (income, expense, investment, liability repayment)
- Auto-classify transactions based on keywords
- Track assets and liabilities
- Calculate net worth
- Monthly cashflow summary

## Tech Stack

- Backend: FastAPI + SQLite
- Frontend: Flutter
